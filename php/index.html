Funciones de Arrays

<?php
$numeros = [1, 2, 3, 4, 5];
$frutas = ["manzana", "banana", "naranja"];

// Agregar elementos
array_push($numeros, 6, 7); // [1,2,3,4,5,6,7]
$numeros[] = 8; // [1,2,3,4,5,6,7,8]

// Eliminar elementos
array_pop($numeros); // elimina último elemento
array_shift($numeros); // elimina primer elemento

// Búsqueda
echo in_array(3, $numeros) ? "Encontrado" : "No encontrado"; // true
echo array_search("banana", $frutas); // 1 (índice)

// Ordenamiento

rsort($numeros); // orden descendente
asort($frutas); // orden alfabético manteniendo índices

// Arrays asociativos
$persona = ["nombre" => "Juan", "edad" => 25, "ciudad" => "Madrid"];
echo array_key_exists("edad", $persona) ? "Clave existe" : "No existe";
echo array_keys($persona); // ["nombre", "edad", "ciudad"]
echo array_values($persona); // ["Juan", 25, "Madrid"]

// Funciones de callback
$numeros_pares = array_filter($numeros, function($n) { return $n % 2 == 0; });
$cuadrados = array_map(function($n) { return $n * $n; }, $numeros);

<?php

Patrón MVC (Model-View-Controller)

MVC es un patrón de arquitectura que separa la lógica de negocio (Model), la presentación (View) y el control de flujo (Controller). Es una buena práctica para mantener el código organizado y mantenible.

¿Por qué usar MVC?

  • Separación de responsabilidades: Cada componente tiene una función específica
  • Mantenibilidad: Fácil modificar una parte sin afectar otras
  • Reutilización: Los modelos pueden usarse en diferentes controladores
  • Testabilidad: Cada componente puede probarse independientemente
  • Escalabilidad: Fácil agregar nuevas funcionalidades

3. Modelo de Usuario

<?php
// models/User.php
class User extends Model {
    public function getAll() {
        $stmt = $this->db->query("SELECT * FROM users");
        return $stmt->fetchAll(PDO::FETCH_ASSOC);
    }
    
    public function getById($id) {
        $stmt = $this->db->prepare("SELECT * FROM users WHERE id = ?");
        $stmt->execute([$id]);
        return $stmt->fetch(PDO::FETCH_ASSOC);
    }
    
    public function create($data) {
        $stmt = $this->db->prepare("INSERT INTO users (name, email) VALUES (?, ?)");
        return $stmt->execute([$data['name'], $data['email']]);
    }
    
    public function update($id, $data) {
        $stmt = $this->db->prepare("UPDATE users SET name = ?, email = ? WHERE id = ?");
        return $stmt->execute([$data['name'], $data['email'], $id]);
    }
    
    public function delete($id) {
        $stmt = $this->db->prepare("DELETE FROM users WHERE id = ?");
        return $stmt->execute([$id]);
    }
}
?>

4. Controlador de Usuario

<?php
// controllers/UserController.php
class UserController extends Controller {
    private $userModel;
    
    public function __construct() {
        $this->userModel = new User();
    }
    
    public function index() {
        $users = $this->userModel->getAll();
        $this->view('user/index', ['users' => $users]);
    }
    
    public function show($id) {
        $user = $this->userModel->getById($id);
        if (!$user) {
            $this->view('errors/404');
            return;
        }
        $this->view('user/show', ['user' => $user]);
    }
    
    public function create() {
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $data = [
                'name' => $_POST['name'],
                'email' => $_POST['email']
            ];
            
            if ($this->userModel->create($data)) {
                $this->redirect('/users');
            } else {
                $this->view('user/create', ['error' => 'Error al crear usuario']);
            }
        } else {
            $this->view('user/create');
        }
    }
    
    public function edit($id) {
        $user = $this->userModel->getById($id);
        
        if ($_SERVER['REQUEST_METHOD'] === 'POST') {
            $data = [
                'name' => $_POST['name'],
                'email' => $_POST['email']
            ];
            
            if ($this->userModel->update($id, $data)) {
                $this->redirect('/users');
            }
        }
        
        $this->view('user/edit', ['user' => $user]);
    }
    
    public function delete($id) {
        if ($this->userModel->delete($id)) {
            $this->redirect('/users');
        }
    }
}
?>

Sistema de Plantillas con Punto de Entrada Único

Un sistema de plantillas permite separar la lógica de presentación, hacer el código más mantenible y crear URLs amigables. Usaremos un único index.php como punto de entrada y .htaccess para reescribir URLs.

Archivo .htaccess

# .htaccess
RewriteEngine On

# Evitar acceso directo a archivos sensibles
RewriteRule ^(core|models|controllers)/ - [F,L]

# Reescribir URLs amigables
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]

# Seguridad adicional
<Files "config.php">
    Order Deny,Allow
    Deny from all
</Files>

# Configuración de PHP
php_value upload_max_filesize 10M
php_value post_max_size 10M
php_value max_execution_time 300

Punto de Entrada Único (index.php)

<?php
// index.php - Punto de entrada único

// Iniciar sesión
session_start();

// Configuración de errores (solo en desarrollo)
ini_set('display_errors', 1);
error_reporting(E_ALL);

// Cargar configuración
require_once 'config.php';

// Autoloader simple para clases
spl_autoload_register(function ($className) {
    $paths = [
        'core/',
        'controllers/',
        'models/'
    ];
    
    foreach ($paths as $path) {
        $file = $path . $className . '.php';
        if (file_exists($file)) {
            require_once $file;
            return;
        }
    }
});

// Función para obtener la URL actual
function getCurrentUrl() {
    $url = isset($_GET['url']) ? $_GET['url'] : 'home/index';
    $url = rtrim($url, '/');
    return explode('/', $url);
}

// Router simple
$url = getCurrentUrl();
$controller = isset($url[0]) ? ucfirst($url[0]) . 'Controller' : 'HomeController';
$method = isset($url[1]) ? $url[1] : 'index';
$params = array_slice($url, 2);

// Verificar si el controlador existe
if (class_exists($controller)) {
    $controllerInstance = new $controller();
    
    // Verificar si el método existe
    if (method_exists($controllerInstance, $method)) {
        // Llamar al método con parámetros
        call_user_func_array([$controllerInstance, $method], $params);
    } else {
        // Método no encontrado
        require_once 'views/errors/404.php';
    }
} else {
    // Controlador no encontrado
    require_once 'views/errors/404.php';
}
?>

Controlador Base Mejorado

<?php
// core/Controller.php
class Controller {
    protected $layout = 'layouts/main';
    
    protected function view($view, $data = [], $layout = null) {
        // Extraer variables del array para usarlas en la vista
        extract($data);
        
        // Usar layout si se especifica
        $layout = $layout ?? $this->layout;
        
        // Iniciar buffer de salida
        ob_start();
        require_once VIEW_PATH . $view . '.php';
        $content = ob_get_clean();
        
        // Incluir layout si existe
        if (file_exists(VIEW_PATH . $layout . '.php')) {
            require_once VIEW_PATH . $layout . '.php';
        } else {
            echo $content;
        }
    }
    
    protected function json($data) {
        header('Content-Type: application/json');
        echo json_encode($data);
        exit;
    }
    
    protected function redirect($url, $statusCode = 302) {
        header('Location: ' . url($url), true, $statusCode);
        exit;
    }
    
    protected function isPost() {
        return $_SERVER['REQUEST_METHOD'] === 'POST';
    }
    
    protected function isAjax() {
        return isset($_SERVER['HTTP_X_REQUESTED_WITH']) && 
               strtolower($_SERVER['HTTP_X_REQUESTED_WITH']) === 'xmlhttprequest';
    }
    
    protected function getPost($key = null, $default = null) {
        if ($key === null) {
            return $_POST;
        }
        return isset($_POST[$key]) ? $_POST[$key] : $default;
    }
    
    protected function getGet($key = null, $default = null) {
        if ($key === null) {
            return $_GET;
        }
        return isset($_GET[$key]) ? $_GET[$key] : $default;
    }
    
    protected function setFlash($message, $type = 'info') {
        $_SESSION['flash'] = [
            'message' => $message,
            'type' => $type
        ];
    }
    
    protected function getFlash() {
        if (isset($_SESSION['flash'])) {
            $flash = $_SESSION['flash'];
            unset($_SESSION['flash']);
            return $flash;
        }
        return null;
    }
}
?>

Ejemplo de Controlador con Sistema de Plantillas

<?php
// controllers/ProductController.php
class ProductController extends Controller {
    private $productModel;
    
    public function __construct() {
        $this->productModel = new Product();
    }
    
    public function index() {
        $products = $this->productModel->getAll();
        
        $this->view('products/index', [
            'title' => 'Lista de Productos',
            'products' => $products
        ]);
    }
    
    public function create() {
        if ($this->isPost()) {
            $data = [
                'name' => $this->getPost('name'),
                'price' => $this->getPost('price'),
                'description' => $this->getPost('description')
            ];
            
            if ($this->productModel->create($data)) {
                $this->setFlash('Producto creado exitosamente', 'success');
                $this->redirect('products');
            } else {
                $this->setFlash('Error al crear el producto', 'danger');
            }
        }
        
        $this->view('products/create', [
            'title' => 'Crear Producto'
        ]);
    }
    
    public function api() {
        // Respuesta JSON para AJAX
        $products = $this->productModel->getAll();
        $this->json(['success' => true, 'data' => $products]);
    }
}
?>

Ventajas del Sistema

  • URLs amigables: /products/create en lugar de index.php?controller=products&action=create
  • Separación clara: Lógica, presentación y datos separados
  • Reutilización: Layouts y componentes compartidos

MySQL con PDO

Conexión PDO

<?php
try {
    $pdo = new PDO("mysql:host=localhost;dbname=base_datos;charset=utf8", "usuario", "password");
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch(PDOException $e) {
    die("Error de conexión: " . $e->getMessage());
}
?>

Operaciones CRUD con PDO

<?php
// INSERT
$sql = "INSERT INTO usuarios (nombre, email, fecha_registro) VALUES (:nombre, :email, NOW())";
$stmt = $pdo->prepare($sql);
$stmt->execute([
    'nombre' => $nombre,
    'email' => $email
]);

// SELECT
$sql = "SELECT * FROM usuarios WHERE activo = :activo ORDER BY fecha_registro DESC";
$stmt = $pdo->prepare($sql);
$stmt->execute(['activo' => 1]);
$usuarios = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($usuarios as $usuario) {
    echo $usuario['nombre'] . "<br>";
}

// UPDATE
$sql = "UPDATE usuarios SET nombre = :nombre WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute([
    'nombre' => $nuevoNombre,
    'id' => $id
]);

// DELETE
$sql = "DELETE FROM usuarios WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute(['id' => $id]);
?>
