Guía Completa de CSS y CSS3

Domina los estilos web con mejores prácticas y técnicas modernas

1. ¿Qué es CSS?

CSS (Cascading Style Sheets) es el lenguaje que da estilo y diseño a las páginas web. Controla colores, fuentes, layouts y animaciones.

Importante: CSS separa el contenido (HTML) del diseño, haciendo el código más mantenible y reutilizable.

Formas de aplicar CSS:

  • Inline: Directamente en la etiqueta HTML (no recomendado)
  • Interno: En la etiqueta <style> del head
  • Externo: Archivo .css separado (recomendado)
<!-- CSS Externo (recomendado) -->
<link rel="stylesheet" href="styles.css">

<!-- CSS Interno -->
<style>
    body { background: #f0f0f0; }
</style>

<!-- CSS Inline (evitar) -->
<p style="color: red;">Texto rojo</p>

2. Selectores CSS

Los selectores indican qué elementos HTML estilizar.

Selectores básicos:

/* Selector de etiqueta */
p { color: blue; }

/* Selector de clase */
.mi-clase { font-size: 18px; }

/* Selector de ID */
#mi-id { background: yellow; }

/* Selector universal */
* { margin: 0; }

Selectores avanzados:

/* Selector descendente */
div p { color: green; }

/* Selector de hijo directo */
div > p { font-weight: bold; }

/* Selector de hermano adyacente */
h1 + p { margin-top: 0; }

/* Selector de atributo */
input[type="text"] { border: 1px solid #ccc; }

/* Pseudo-clases */
a:hover { color: red; }
li:nth-child(even) { background: #f0f0f0; }

/* Pseudo-elementos */
p::first-letter { font-size: 2em; }
div::before { content: "→"; }

3. Modelo de Caja (Box Model)

Todo elemento HTML es una caja rectangular con contenido, padding, borde y margin.

Contenido

.caja {
    width: 200px;
    height: 100px;
    padding: 20px;        /* Espacio interno */
    border: 2px solid #000; /* Borde */
    margin: 10px;         /* Espacio externo */
    background: lightblue;
}

/* Box-sizing: border-box incluye padding y borde en el ancho total */
.caja-moderna {
    box-sizing: border-box;
    width: 200px;
    padding: 20px;
    border: 2px solid #000;
}

4. Posicionamiento

Position:

/* Static: posición normal (default) */
.static { position: static; }

/* Relative: relativo a su posición normal */
.relative {
    position: relative;
    top: 10px;
    left: 20px;
}

/* Absolute: relativo al ancestro posicionado más cercano */
.absolute {
    position: absolute;
    top: 0;
    right: 0;
}

/* Fixed: fijo en la ventana del navegador */
.fixed {
    position: fixed;
    bottom: 20px;
    right: 20px;
}

/* Sticky: se pega al hacer scroll */
.sticky {
    position: sticky;
    top: 0;
}

Float y Clear:

.izquierda { float: left; width: 50%; }
.derecha { float: right; width: 50%; }

/* Limpiar floats */
.clearfix::after {
    content: "";
    clear: both;
    display: table;
}

5. Flexbox

Flexbox es un modelo de layout moderno para crear diseños flexibles.

.contenedor-flex {
    display: flex;
    justify-content: space-between; /* Alineación horizontal */
    align-items: center;           /* Alineación vertical */
    flex-wrap: wrap;               /* Envolver elementos */
}

.item-flex {
    flex: 1;                       /* Crecer para ocupar espacio */
    min-width: 200px;
}

Propiedades principales:

  • display: flex - Activa flexbox
  • justify-content - Alineación horizontal
  • align-items - Alineación vertical
  • flex-direction - Dirección (row/column)
  • flex-wrap - Envolver elementos
  • flex - Controlar crecimiento de items

.item-especial {
    grid-column: 1 / 3;  /* Ocupa columnas 1 y 2 */
    grid-row: 1 / 3;     /* Ocupa filas 1 y 2 */
}

7. CSS3: Transiciones y Animaciones

Transiciones:

.boton {
    background: #007bff;
    transition: background-color 0.3s ease;
}

.boton:hover {
    background: #0056b3;
}

Animaciones:

@keyframes girar {
    from { transform: rotate(0deg); }
    to { transform: rotate(360deg); }
}

.elemento-animado {
    animation: girar 2s infinite linear;
}

Transformaciones:

.transformado {
    transform: translateX(50px) rotate(45deg) scale(1.2);
    transform-origin: center;
}

8. Responsive Design

Media queries permiten adaptar el diseño a diferentes tamaños de pantalla.

/* Mobile first */
.contenedor {
    width: 100%;
    padding: 10px;
}

/* Tablet */
@media (min-width: 768px) {
    .contenedor {
        width: 750px;
        margin: 0 auto;
        padding: 20px;
    }
}

/* Desktop */
@media (min-width: 992px) {
    .contenedor {
        width: 970px;
    }
}

/* Large desktop */
@media (min-width: 1200px) {
    .contenedor {
        width: 1170px;
    }
}

Unidades responsivas:

  • vw/vh - Viewport width/height (1% del viewport)
  • em/rem - Relativo al tamaño de fuente
  • % - Porcentaje del elemento padre

9. Mejores Prácticas

Organización del código:

  • BEM: Block Element Modifier (ej: .header__title--large)
  • SMACSS: Categorías: Base, Layout, Module, State, Theme
  • Atomic CSS: Clases pequeñas y reutilizables

BEM en práctica:

/* Bloque */
.boton { }

/* Elemento */
.boton__icono { }

/* Modificador */
.boton--primario { }
.boton--grande { }

Performance:

  • Minimiza el CSS
  • Usa sprites para iconos
  • Evita !important innecesario
  • Optimiza imágenes
  • Usa CSS crítico inline

Mantenibilidad:

  • Usa variables CSS para colores y medidas
  • Documenta tu CSS
  • Evita la especificidad excesiva
  • Reutiliza estilos comunes

10. Variables CSS y Funciones

:root {
    --color-primario: #007bff;
    --espacio-pequeno: 8px;
    --fuente-principal: 'Arial', sans-serif;
}

.boton {
    background: var(--color-primario);
    padding: var(--espacio-pequeno);
    font-family: var(--fuente-principal);
}

/* Funciones CSS */
.calculo {
    width: calc(100% - 20px);
    height: min(500px, 80vh);
}
