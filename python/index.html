🐍 Python desde Cero

Esta guía te introduce a Python como lenguaje, desde la instalación hasta los conceptos básicos necesarios para comenzar a crear aplicaciones web, automatizaciones y análisis de datos.

¿Qué es Python?

Python es un lenguaje de programación interpretado, de alto nivel y con sintaxis clara. Es ideal para aprender programación, desarrollar aplicaciones web, automatizar tareas, analizar datos y construir modelos avanzados.

Ventajas de Python

  • Fácil de leer: Sintaxis simple y expresiva.
  • Multipropósito: Web, datos, automatización, ciencia, scripting.
  • Gran comunidad: Librerías y recursos abundantemente disponibles.
  • Productividad: Menos código para hacer más cosas.
  • Portable: Funciona en Windows, macOS y Linux.

Flujo de Aprendizaje en Python

Este curso te guía paso a paso, desde los fundamentos hasta usar Python en web y datos:

  1. Instalación y entorno: configura Python y entornos virtuales.
  2. Conceptos básicos: variables, tipos, operadores y estructuras de datos.
  3. Control de flujo: aprende condicionales y bucles.
  4. Funciones: crea bloques reutilizables y limpia tu código.
  5. POO: modela datos con clases y objetos.
  6. Aplicaciones web: pasa a Django y Flask para construir sitios y APIs.
  7. Análisis de datos: usa pandas, NumPy y visualización para extraer valor de los datos.
  8. Proyectos prácticos: combina todo en aplicaciones reales y portafolios.

Avanza hacia estos recursos cuando estés listo:

  • Django
  • Flask
  • Análisis de Datos
  • SQLite

Instalación y Entorno

Comenzar en Python requiere crear un entorno virtual y tener el intérprete instalado. Esto evita conflictos entre versiones y dependencias.

# Verificar versión de Python
python --version

# Crear entorno virtual
python -m venv venv

# Activar entorno virtual - Windows
venv\Scripts\activate

# Activar entorno virtual - macOS / Linux
source venv/bin/activate

# Actualizar pip y comprobar instalación
python -m pip install --upgrade pip
pip --version

Recomendación

Siempre usa un entorno virtual para cada proyecto y guarda las dependencias en requirements.txt.

Control de Flujo

Condicionales

edad = 20
if edad >= 18:
    print('Eres mayor de edad')
elif edad >= 13:
    print('Eres adolescente')
else:
    print('Eres niño')

Bucle for

nombres = ['Ana', 'Luis', 'Marta']
for nombre in nombres:
    print(nombre)

for i in range(5):
    print(i)

Bucle while

contador = 0
while contador < 5:
    print(contador)
    contador += 1

Funciones

Las funciones agrupan lógica reutilizable y hacen el código más limpio y mantenible.

def saludar(nombre):
    return f'Hola, {nombre}!'

mensaje = saludar('Ana')
print(mensaje)

# Función con valores por defecto
def potencia(base, exponente=2):
    return base ** exponente

print(potencia(5))  # 25
print(potencia(5, 3))  # 125

Programación Orientada a Objetos

Python permite definir clases y objetos para modelar datos y comportamientos.

class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def presentarse(self):
        return f'Mi nombre es {self.nombre} y tengo {self.edad} años.'

persona = Persona('Ana', 28)
print(persona.presentarse())
