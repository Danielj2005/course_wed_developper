📊 Análisis de Datos con Python

Esta guía introduce el flujo básico de análisis de datos con Python: cargar datos, limpiar, explorar, visualizar y extraer conclusiones usando librerías estándar.

¿Por qué usar Python para análisis de datos?

  • Python cuenta con herramientas potentes como pandas, numpy, matplotlib y seaborn.
  • Es fácil pasar de datos en bruto a resultados visuales.
  • Permite automatizar procesos y crear pipelines de análisis reproducibles.
  • Es la base para ciencia de datos y machine learning.

Instalación de librerías

pip install pandas numpy matplotlib seaborn scikit-learn

Estas librerías te permiten manipular tablas, hacer cálculos numéricos y crear gráficos para explorar la información.

Pandas - Manipulación de Datos

Cargar datos

import pandas as pd

# Cargar un archivo CSV
ruta = 'datos/ventas.csv'
df = pd.read_csv(ruta)
print(df.head())

Exploración inicial

print(df.info())
print(df.describe())
print(df.columns)
print(df.isnull().sum())

Limpieza de datos

# Eliminar filas con valores faltantes
 df = df.dropna()

# Cambiar tipos de datos
df['fecha'] = pd.to_datetime(df['fecha'])

# Rellenar valores nulos
df['categoria'].fillna('Desconocido', inplace=True)

# Eliminar duplicados
df = df.drop_duplicates()

Agrupaciones y resúmenes

ventas_por_mes = df.groupby(df['fecha'].dt.to_period('M')).sum()
print(ventas_por_mes)

ventas_por_categoria = df.groupby('categoria')['monto'].sum().reset_index()
print(ventas_por_categoria)

NumPy - Cálculos numéricos

Uso básico

import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr.mean())
print(arr.std())
print(arr.sum())

matriz = np.array([[1, 2], [3, 4]])
print(np.linalg.inv(matriz))

Integración con pandas

df['monto_normalizado'] = (df['monto'] - df['monto'].mean()) / df['monto'].std()
print(df.head())

Visualización

Gráficos con Matplotlib

import matplotlib.pyplot as plt

plt.figure(figsize=(8, 5))
plt.plot(df['fecha'], df['monto'], marker='o')
plt.title('Ventas por Fecha')
plt.xlabel('Fecha')
plt.ylabel('Monto')
plt.grid(True)
plt.show()

Gráficos con Seaborn

import seaborn as sns

sns.set(style='whitegrid')
plt.figure(figsize=(10, 6))
sns.barplot(x='categoria', y='monto', data=ventas_por_categoria)
plt.title('Ventas por Categoría')
plt.xticks(rotation=45)
plt.show()

Proyecto de ejemplo

  1. Cargar un dataset real (CSV o Excel) con pandas.
  2. Inspeccionar columnas, tipos y valores faltantes.
  3. Limpiar datos y transformar columnas clave.
  4. Generar métricas como totales, promedios y distribución.
  5. Crear gráficos ejecutables para visualizar patrones.
# Ejemplo de análisis simple
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

ruta = 'datos/ventas.csv'
df = pd.read_csv(ruta)
df['fecha'] = pd.to_datetime(df['fecha'])
df = df.dropna(subset=['monto'])

grupo = df.groupby('categoria')['monto'].sum().reset_index()

sns.barplot(x='categoria', y='monto', data=grupo)
plt.title('Ventas por Categoría')
plt.xticks(rotation=45)
plt.tight_layout()
plt.show()
