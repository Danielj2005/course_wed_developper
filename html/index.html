Guía de HTML y Bootstrap

Aprende HTML semántico, SEO y construcción rápida con Bootstrap

1. ¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje que estructura el contenido de las páginas web. Define elementos como párrafos, encabezados, imágenes y enlaces.

Importante: HTML no es un lenguaje de programación, sino de marcado. Se enfoca en la estructura y el significado del contenido.

2. HTML Semántico

El HTML semántico usa etiquetas que describen el significado del contenido, no solo su apariencia. Esto mejora la accesibilidad, SEO y mantenibilidad.

Etiquetas semánticas principales:

  • <header> - Cabecera de la página o sección
  • <nav> - Navegación
  • <main> - Contenido principal
  • <section> - Sección de contenido
  • <article> - Contenido independiente
  • <aside> - Contenido lateral
  • <footer> - Pie de página
<!-- Estructura semántica básica -->
<header>
    <h1>Título de la página</h1>
</header>

<nav>
    <ul>
        <li><a href="#inicio">Inicio</a></li>
        <li><a href="#acerca">Acerca de</a></li>
    </ul>
</nav>

<main>
    <section id="inicio">
        <h2>Bienvenido</h2>
        <p>Contenido principal aquí.</p>
    </section>
</main>

<footer>
    <p>© 2024 Mi Sitio Web</p>
</footer>

3. SEO (Search Engine Optimization)

El SEO optimiza tu sitio para que aparezca en los resultados de búsqueda. Incluye técnicas técnicas y de contenido.

Elementos esenciales para SEO:

  • Título de página: Describe claramente el contenido
  • Meta description: Resumen atractivo de la página
  • Encabezados (H1-H6): Estructura jerárquica del contenido
  • Atributos alt en imágenes: Descripción para motores de búsqueda
  • URLs amigables: Legibles y descriptivas
  • Contenido de calidad: Información útil y relevante
<!-- Ejemplo de head optimizado para SEO -->
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Guía Completa de JavaScript para Principiantes</title>
    <meta name="description" content="Aprende JavaScript desde cero con ejemplos prácticos, proyectos y mejores prácticas para desarrolladores web.">
    <meta name="keywords" content="javascript, tutorial, principiantes, desarrollo web">
    <link rel="canonical" href="https://misitio.com/guia-javascript">
</head>

Consejos para SEO en HTML:

  • Usa solo un H1 por página
  • Estructura los encabezados en orden jerárquico (H1 → H2 → H3)
  • Incluye palabras clave relevantes en títulos y contenido
  • Optimiza la velocidad de carga
  • Asegura que el sitio sea móvil-friendly

4. Introducción a Bootstrap

Bootstrap es un framework CSS que acelera el desarrollo de interfaces responsivas. Incluye componentes pre-diseñados y un sistema de grid.

¿Por qué usar Bootstrap?

  • Rápido: Componentes listos para usar
  • Responsivo: Se adapta a móviles, tablets y desktop
  • Consistente: Diseño uniforme
  • Personalizable: Puedes modificar estilos

Instalación:

<!-- Agrega esto en el <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Agrega esto antes del cierre de </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>

9. Buenas Prácticas

  • HTML semántico: Usa las etiquetas correctas para el contenido
  • SEO primero: Optimiza títulos, meta tags y estructura antes del diseño
  • Responsive: Siempre diseña mobile-first con Bootstrap
  • Accesibilidad: Usa atributos alt, labels y navegación por teclado
  • Rendimiento: Minimiza CSS/JS y optimiza imágenes
  • Mantenibilidad: Usa clases de Bootstrap consistentes

10. Proyecto Práctico: Página de Portafolio

Aquí tienes un ejemplo completo de una página de portafolio usando HTML semántico, SEO y Bootstrap.

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi Portafolio - Desarrollador Web</title>
    <meta name="description" content="Portafolio de Juan Pérez, desarrollador web especializado en JavaScript y React.">
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
    <header class="bg-dark text-white py-5">
        <div class="container">
            <h1>Juan Pérez</h1>
            <p class="lead">Desarrollador Web Full Stack</p>
        </div>
    </header>

    <nav class="navbar navbar-expand-lg navbar-dark bg-dark">
        <div class="container">
            <a class="navbar-brand" href="#">Mi Portafolio</a>
            <div class="navbar-nav">
                <a class="nav-link" href="#proyectos">Proyectos</a>
                <a class="nav-link" href="#contacto">Contacto</a>
            </div>
        </div>
    </nav>

    <main class="container my-5">
        <section id="proyectos">
            <h2>Mis Proyectos</h2>
            <div class="row">
                <div class="col-md-4">
                    <div class="card">
                        <div class="card-body">
                            <h5 class="card-title">Proyecto 1</h5>
                            <p class="card-text">Descripción del proyecto.</p>
                        </div>
                    </div>
                </div>
            </div>
        </section>
    </main>

    <footer class="bg-dark text-white text-center py-3">
        <p>© 2024 Juan Pérez</p>
    </footer>

    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
</body>
</html>
