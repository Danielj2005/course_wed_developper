# Curso Completo de Desarrollo Web

Este repositorio contiene una guía didáctica completa para aprender desarrollo web desde cero hasta niveles avanzados. Incluye teoría, ejemplos prácticos, frameworks modernos y un camino completo para formarte como desarrollador full-stack.

## 🚀 Estructura del curso

### 1. Nivel Principiante
- `html/index.html` — HTML5 y Bootstrap.
- `css-css3/index.html` — CSS3, diseño responsivo, animaciones y layout.
- `guia_aprendizaje_js.js` — JavaScript básico, DOM y programación esencial.

### 2. Nivel Intermedio
- `tailwind/index.html` — Tailwind CSS para estilos modernos y utilitarios.
- `mern/react/index.html` — React.js, componentes, hooks y estado.
- `mysql-postgresql/index.html` — Fundamentos de bases de datos SQL, consultas y diseño.

### 3. Nivel Avanzado
- `mern/nodejs/index.html` — Node.js como runtime, asincronía y módulos.
- `mern/express/index.html` — Express.js para APIs, routing y middleware.
- `mern/mongodb/index.html` — MongoDB y conceptos NoSQL.
- `mern/integracion/index.html` — Integración completa del stack MERN.
- `laravel-11/index.html` — Laravel 11 para desarrollo full-stack con PHP.
- `php/index.html` — Curso completo de PHP, MVC, templates y mejores prácticas.

### 4. Ecosistema Python
- `python/index.html` — Python desde cero: instalación, sintaxis, estructuras y POO.
- `python/django/index.html` — Desarrollo web con Django.
- `python/flask/index.html` — Desarrollo web con Flask.
- `python/sqlite/index.html` — SQLite para bases de datos ligeras y locales.
- `python/analisis-datos/index.html` — Análisis de datos con pandas, NumPy, matplotlib y seaborn.

## 📚 Qué encontrarás en cada módulo

- Fundamentos de HTML y CSS para construir estructuras y estilo.
- JavaScript moderno: variables, funciones, eventos, asincronía y programación orientada a objetos.
- Frameworks de frontend: Tailwind CSS y React.
- Backend con PHP, Node.js, Express y Laravel.
- Bases de datos SQL y NoSQL (MySQL, PostgreSQL, MongoDB, SQLite).
- Python completo y análisis de datos con librerías clave.
- Proyectos prácticos y rutas de aprendizaje claras.

## 🧭 Cómo usar este repositorio

1. Abre `index.html` en un navegador o en un servidor local.
2. Navega por los módulos y selecciona el tema que quieras estudiar.
3. Sigue la progresión del curso: Principiante → Intermedio → Avanzado.
4. Usa los enlaces de cada módulo para acceder a los ejercicios y ejemplos.

## 💡 Recomendación

Empieza por `html/index.html` y `css-css3/index.html` si eres principiante. Luego avanza a JavaScript y Frameworks. Finalmente, explora backend y Python para convertir tus conocimientos en aplicaciones full-stack.
