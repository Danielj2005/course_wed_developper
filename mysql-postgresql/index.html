Introducción a las Bases de Datos

Las bases de datos son sistemas organizados para almacenar, gestionar y recuperar información. SQL es el lenguaje estándar para interactuar con bases de datos relacionales.

¿Qué aprenderás?

  • Conceptos fundamentales de SQL

  • DML (Data Manipulation Language)
  • DCL (Data Control Language)
  • Funciones y procedimientos almacenados
  • Optimización y mejores prácticas
  • Diferencias entre MySQL y PostgreSQL

SQL Básico

Crear Tabla

CREATE TABLE usuarios (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nombre VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    fecha_registro TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    activo BOOLEAN DEFAULT TRUE
);

Insertar Datos

INSERT INTO usuarios (nombre, email) 
VALUES ('Juan Pérez', 'juan@email.com'),
       ('María García', 'maria@email.com'),
       ('Carlos López', 'carlos@email.com');

Consultar Datos

-- Seleccionar todos los usuarios
SELECT * FROM usuarios;

-- Seleccionar campos específicos
SELECT nombre, email FROM usuarios WHERE activo = TRUE;

-- Con JOIN
SELECT u.nombre, p.titulo 
FROM usuarios u 
JOIN posts p ON u.id = p.usuario_id;

-- Con agrupación
SELECT COUNT(*) as total, activo 
FROM usuarios 
GROUP BY activo;

Actualizar y Eliminar

-- Actualizar
UPDATE usuarios 
SET nombre = 'Juan Carlos Pérez', email = 'juancarlos@email.com' 
WHERE id = 1;

-- Eliminar
DELETE FROM usuarios WHERE id = 3;

Funciones Agregadas

SELECT 
    COUNT(*) as total_usuarios,
    AVG(edad) as edad_promedio,
    MAX(fecha_registro) as ultimo_registro,
    MIN(fecha_registro) as primer_registro
FROM usuarios;

MySQL

MySQL es uno de los sistemas de gestión de bases de datos más populares, conocido por su velocidad y facilidad de uso.

Características Específicas de MySQL

-- Tipos de datos específicos
CREATE TABLE productos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(255) NOT NULL,
    precio DECIMAL(10,2) NOT NULL,
    descripcion TEXT,
    imagen LONGBLOB,
    fecha_creacion TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Índices
CREATE INDEX idx_nombre ON productos (nombre);
CREATE FULLTEXT INDEX idx_descripcion ON productos (descripcion);

-- Motores de almacenamiento
CREATE TABLE logs (
    id INT AUTO_INCREMENT PRIMARY KEY,
    mensaje TEXT,
    fecha TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE = MyISAM;

-- Procedimientos almacenados
DELIMITER //
CREATE PROCEDURE obtener_usuario(IN user_id INT)
BEGIN
    SELECT * FROM usuarios WHERE id = user_id;
END //
DELIMITER ;

-- Triggers
DELIMITER //
CREATE TRIGGER actualizar_fecha_modificacion 
BEFORE UPDATE ON usuarios
FOR EACH ROW
BEGIN
    SET NEW.fecha_modificacion = NOW();
END //
DELIMITER ;

Optimización en MySQL

  • Usar EXPLAIN para analizar consultas
  • Crear índices apropiados
  • Usar LIMIT en consultas grandes
  • Normalizar tablas cuando sea necesario
  • Usar prepared statements

PostgreSQL

PostgreSQL es un sistema de gestión de bases de datos objeto-relacional avanzado, conocido por su robustez y cumplimiento de estándares SQL.

Características Avanzadas de PostgreSQL

-- Tipos de datos avanzados
CREATE TABLE documentos (
    id SERIAL PRIMARY KEY,
    titulo VARCHAR(255) NOT NULL,
    contenido TEXT,
    metadata JSONB,
    ubicacion GEOMETRY,
    etiquetas TEXT[],
    fecha_creacion TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

-- Arrays
INSERT INTO documentos (titulo, etiquetas) 
VALUES ('Documento 1', ARRAY['importante', 'urgente']);

-- JSONB
UPDATE documentos 
SET metadata = '{"autor": "Juan", "version": 1.2, "revisado": true}'
WHERE id = 1;

-- Consultas JSON
SELECT titulo, metadata->'autor' as autor 
FROM documentos 
WHERE metadata->>'revisado' = 'true';

-- Funciones avanzadas
CREATE OR REPLACE FUNCTION calcular_promedio_notas()
RETURNS DECIMAL AS $$
DECLARE
    promedio DECIMAL;
BEGIN
    SELECT AVG(nota) INTO promedio FROM calificaciones;
    RETURN promedio;
END;
$$ LANGUAGE plpgsql;

-- Triggers con funciones
CREATE OR REPLACE FUNCTION actualizar_promedio()
RETURNS TRIGGER AS $$
BEGIN
    UPDATE estudiantes 
    SET promedio = calcular_promedio_notas()
    WHERE id = NEW.estudiante_id;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trigger_actualizar_promedio
    AFTER INSERT OR UPDATE ON calificaciones
    FOR EACH ROW EXECUTE FUNCTION actualizar_promedio();

Ventajas de PostgreSQL

  • Tipos de datos avanzados (JSONB, arrays, geometría)
  • Mejor soporte para transacciones complejas
  • Extensiones poderosas
  • Mejor cumplimiento de estándares SQL
  • Soporte nativo para UUID, rangos, etc.

Ejemplos Prácticos

E-commerce: Sistema de Productos y Pedidos

-- Tabla de productos
CREATE TABLE productos (
    id SERIAL PRIMARY KEY,
    nombre VARCHAR(255) NOT NULL,
    descripcion TEXT,
    precio DECIMAL(10,2) NOT NULL,
    stock INT DEFAULT 0,
    categoria_id INT REFERENCES categorias(id)
);

-- Tabla de pedidos
CREATE TABLE pedidos (
    id SERIAL PRIMARY KEY,
    usuario_id INT REFERENCES usuarios(id),
    fecha_pedido TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    estado VARCHAR(50) DEFAULT 'pendiente',
    total DECIMAL(10,2)
);

-- Tabla de detalle de pedidos
CREATE TABLE pedido_detalles (
    id SERIAL PRIMARY KEY,
    pedido_id INT REFERENCES pedidos(id),
    producto_id INT REFERENCES productos(id),
    cantidad INT NOT NULL,
    precio_unitario DECIMAL(10,2) NOT NULL
);

-- Consulta compleja
SELECT 
    p.id,
    p.nombre,
    SUM(pd.cantidad) as total_vendido,
    SUM(pd.cantidad * pd.precio_unitario) as ingresos
FROM productos p
JOIN pedido_detalles pd ON p.id = pd.producto_id
JOIN pedidos pe ON pd.pedido_id = pe.id
WHERE pe.fecha_pedido >= '2024-01-01'
GROUP BY p.id, p.nombre
ORDER BY ingresos DESC;

Blog: Sistema de Artículos y Comentarios

-- Tabla de artículos
CREATE TABLE articulos (
    id SERIAL PRIMARY KEY,
    titulo VARCHAR(255) NOT NULL,
    contenido TEXT NOT NULL,
    autor_id INT REFERENCES usuarios(id),
    fecha_publicacion TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP,
    publicado BOOLEAN DEFAULT FALSE
);

-- Tabla de comentarios
CREATE TABLE comentarios (
    id SERIAL PRIMARY KEY,
    articulo_id INT REFERENCES articulos(id),
    usuario_id INT REFERENCES usuarios(id),
    contenido TEXT NOT NULL,
    fecha_comentario TIMESTAMPTZ DEFAULT CURRENT_TIMESTAMP
);

-- Vista para artículos publicados con comentarios
CREATE VIEW articulos_comentarios AS
SELECT 
    a.id,
    a.titulo,
    a.fecha_publicacion,
    u.nombre as autor,
    COUNT(c.id) as num_comentarios
FROM articulos a
JOIN usuarios u ON a.autor_id = u.id
LEFT JOIN comentarios c ON a.id = c.articulo_id
WHERE a.publicado = TRUE
GROUP BY a.id, a.titulo, a.fecha_publicacion, u.nombre;
