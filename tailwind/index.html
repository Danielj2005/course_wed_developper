1. ¿Qué es Tailwind CSS?

Tailwind CSS es un framework CSS utility-first que proporciona clases de bajo nivel para construir diseños personalizados sin salir de tu HTML.

✅ Ventajas:

  • Rápido desarrollo de prototipos
  • Consistencia visual
  • Altamente personalizable
  • Archivo CSS pequeño (con PurgeCSS)
  • Responsive por defecto

❌ Desventajas:

  • Curva de aprendizaje inicial
  • HTML más verboso
  • Requiere configuración

🎯 ¿Cuándo usar Tailwind?

  • Proyectos con diseños únicos y personalizados
  • Equipos que necesitan consistencia
  • Aplicaciones web modernas (React, Vue, etc.)
  • Prototipado rápido

2. Instalación y Configuración

Opción 1: CDN (Para desarrollo rápido)

<script src="https://cdn.tailwindcss.com"></script>

Opción 2: Instalación completa (Recomendado)

# Instalar Tailwind
npm install -D tailwindcss
npx tailwindcss init

# Configurar en tu CSS
@tailwind base;
@tailwind components;
@tailwind utilities;

Configuración básica (tailwind.config.js)

/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./src/**/*.{html,js}"],
  theme: {
    extend: {
      colors: {
        'brand': '#1da1f2',
      }
    },
  },
  plugins: [],
}

5. Diseño Responsive

Tailwind incluye breakpoints responsivos por defecto:

Col 1
Col 2
Col 3
<!-- Breakpoints: sm, md, lg, xl, 2xl -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
  <div>Col 1</div>
  <div>Col 2</div>
  <div>Col 3</div>
</div>

<!-- Texto responsive -->
<p class="text-sm md:text-base lg:text-lg">Texto responsivo</p>

<!-- Espaciado responsive -->
<div class="p-2 md:p-4 lg:p-6">Padding responsivo</div>

Breakpoints por defecto:

  • sm: 640px y superior
  • md: 768px y superior
  • lg: 1024px y superior
  • xl: 1280px y superior
  • 2xl: 1536px y superior

6. Estados y Componentes Personalizados

Estados (Pseudo-clases)

<button class="bg-blue-500 hover:bg-blue-700
                       text-white font-bold py-2 px-4 rounded
                       transition duration-300">
  Hover me!
</button>

Componentes personalizados

<!-- En tu CSS personalizado -->
@layer components {
  .btn-primary {
    @apply bg-blue-500 hover:bg-blue-700 text-white
           font-bold py-2 px-4 rounded transition duration-300;
  }

  .card {
    @apply bg-white rounded-lg shadow-md p-6;
  }
}

<!-- En tu HTML -->
<button class="btn-primary">Botón personalizado</button>
<div class="card">Contenido de la card</div>

Grupos y peer

Texto que cambia al hacer hover en el grupo

<div class="group">
  <p class="group-hover:text-blue-500">Texto</p>
  <button class="group-hover:bg-blue-500">Botón</button>
</div>

7. Mejores Prácticas

Organización del código

  • Usa @apply para componentes reutilizables: Evita repetir clases largas
  • Configura colores y espaciado personalizados: Mantén consistencia
  • Usa capas (@layer): Organiza base, components y utilities
  • Purga CSS no usado: Reduce el tamaño del archivo final

Performance

  • Habilita la purga de CSS en producción
  • Usa CDN para desarrollo rápido
  • Minimiza el CSS final
  • Evita !important cuando sea posible

Convenciones de nomenclatura

<!-- ✅ Bueno -->
<button class="bg-blue-500 hover:bg-blue-700 px-4 py-2 rounded">
  Guardar
</button>

<!-- ❌ Evitar -->
<button style="background: blue; padding: 0.5rem 1rem;">
  Guardar
</button>

Estructura de proyecto recomendada

│   │   ├── main.css          # @tailwind imports
│   │   └── components.css    # Componentes personalizados

│   │   └── main.js
│   └── index.html
├── tailwind.config.js        # Configuración
├── package.json
└── postcss.config.js
